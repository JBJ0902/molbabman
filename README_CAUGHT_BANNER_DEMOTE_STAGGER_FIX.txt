# 적발 사유 배너 / 강등 말풍선 겹침 수정 패치

## 문제

밥 먹다 걸렸을 때 또는 김치 먹다 걸렸을 때:

- `밥 먹다 걸림!`
- `김치 소리 감지!`

중앙 배너가 뜨는 동시에,

- `인턴으로 강등!`
- `인인턴으로 강등!`

말풍선이 같이 떠서 서로 겹쳐 보이지 않는 문제가 있었습니다.

## 수정 내용

기존:
1. 적발 사유 배너 표시
2. 강등 말풍선 동시 표시
3. 두 UI가 겹침

변경 후:
1. `밥 먹다 걸림!` 또는 `김치 소리 감지!`를 먼저 약 0.9초 표시
2. 약 0.98초 뒤 `인턴으로 강등!` 말풍선 표시
3. 적발 사유와 강등 결과가 순서대로 보임

## 음성

강등 음성은 두 번째 말풍선 쪽에서 재생되도록 유지했습니다.
밥/김치 적발 효과음은 첫 번째 적발 배너 시점에 유지됩니다.

## GitHub 적용 방법

이미 GitHub Pages에 올린 상태라면:

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
