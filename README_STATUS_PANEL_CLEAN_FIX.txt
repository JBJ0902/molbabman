# 우측 하단 상태창 미니멀 정리 패치

## 문제

우측 하단 상태창에 긴 설명문과 조작키 안내가 한꺼번에 들어가서
게임 화면이 복잡하고 지저분해 보였습니다.

## 수정 내용

1. 상태창 크기와 높이 축소
2. 상태 문구를 1~2줄 중심으로 정리
3. 긴 조작키 설명을 짧은 칩 UI로 변경
   - `SPACE 밥`
   - `K 김치`
   - `O/ESC 옵션`
   - `M 음성`
   - `R 재시작`
4. `상태` 제목 옆에 작은 STATUS 배지 추가
5. 긴 상태 문구 일부를 짧게 축약
6. 모바일/좁은 화면에서도 덜 답답하게 보이도록 조정

## GitHub 적용 방법

이미 GitHub Pages에 올린 상태라면:

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
