# R 키 현재 스테이지 재시작 패치

## 추가 기능

게임 중 `R` 키를 누르면 현재 플레이 중인 스테이지를 처음부터 다시 시작합니다.

## 초기화되는 항목

- 현재 스테이지 점수
- 현재 스테이지 타이머
- 소음 경계도
- 콤보
- 몰밥 횟수
- 목표 점수 진행도
- 현재 음성/말풍선/경고 상태

## 유지되는 항목

- 현재 스테이지 번호
- 이전 스테이지까지 누적 총점
- 최고점수 기록
- 엔딩 갤러리 해금 기록
- 옵션/사운드 설정
- 목표 미달 누적 경고 횟수

## 사용 예시

STAGE 4에서 R 키 입력 → STAGE 4 처음부터 재시작

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
