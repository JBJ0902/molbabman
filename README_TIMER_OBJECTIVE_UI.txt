# 타이머 목표 UI / 자동 클리어 방지 패치 v9.18.26

## 추가된 UI

좌측 남은 시간 패널 안에 아래 항목을 추가했습니다.

- 목표 점수 현재 / 목표
- 몰밥 횟수 현재 / 목표
- 각 항목별 미니 진행 게이지
- 목표 달성 시 초록색 완료 표시

상단 HUD는 건드리지 않았습니다.

## 클리어 조건 변경

기존:
- 시간이 0초가 되면 자동 클리어

변경:
- 시간이 0초가 되었을 때
- 목표 점수 달성
- 몰밥 횟수 달성
- 위 두 조건을 모두 만족해야 클리어

목표를 못 채우면:
- 목숨 1개 차감
- 계급 1단계 강등
- 같은 스테이지 재도전

목숨이 0개가 되면 기존처럼 로켓 방출/게임오버 처리됩니다.

## 몰밥 횟수 기준

밥 또는 김치를 계속 먹고 있을 때 약 0.65초마다 1회 증가합니다.
짧게 누르기만 하는 것이 아니라 실제로 먹고 있는 시간이 반영됩니다.

## 적용 방법

1. 압축을 풉니다.
2. index.html을 기존 게임 폴더의 index.html에 덮어쓰기합니다.
3. assets 폴더는 그대로 유지합니다.
