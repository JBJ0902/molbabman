# 엔딩 결과/온라인 랭킹 화면 상하 잘림 방지 패치

## 문제

Supabase 온라인 랭킹 박스가 추가되면서 엔딩 결과 화면의 전체 높이가 커졌습니다.
기존 `#endOverlay`는 가운데 정렬 고정 구조라서 화면 높이가 부족하면 위/아래가 잘려 보였습니다.

## 수정 내용

1. 엔딩 결과 오버레이를 상단 기준 정렬로 변경
2. 화면 높이를 넘으면 패널 내부만 스크롤되도록 변경
3. 제목/설명/기록/랭킹/엔딩 배지 간격 압축
4. 온라인 랭킹 리스트 높이 제한
5. 버튼 크기와 간격 축소
6. 820px 이하 높이 화면에서는 미니 컬렉션 박스를 숨겨 잘림 방지
7. 모바일 화면에서는 버튼을 세로 정렬

## GitHub 적용 방법

이번 패치는 `index.html`만 교체하면 됩니다.

1. index.html 전용 ZIP 압축 풀기
2. GitHub 저장소의 index.html 교체
3. Commit changes
4. Pages 재배포 완료 대기
5. 게임 페이지에서 Ctrl + F5
