# 엔딩 갤러리 버튼 클릭 보정 패치 v9.18.27

## 원인

엔딩 일러스트 화면에서 `엔딩 갤러리` 버튼을 누르면,
갤러리 오버레이는 열리지만 기존 엔딩 일러스트 오버레이가 계속 위에 남아 있었습니다.

그래서 사용자가 보기에는 버튼이 안 눌리는 것처럼 보였습니다.

## 수정 내용

1. `openEndingGallery()` 실행 시 `endingIllustrationOverlay`를 먼저 숨김
2. `endingGalleryOverlay`를 더 높은 z-index로 표시
3. 엔딩 일러스트 화면의 `엔딩 갤러리` 버튼에 별도 보정 이벤트 추가
4. 기존 엔딩 결과창/시작 메뉴의 엔딩 갤러리 버튼은 그대로 동작

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
4. 브라우저에서 Ctrl + F5로 강제 새로고침합니다.
