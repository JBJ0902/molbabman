# 몰밥 먹다 경고 4/5 계급 방출 표시 수정 패치

## 문제

`몰밥 먹다 경고 4/5` 상태인데 상단 HUD의 계급이 `방출`로 표시되는 문제가 있었습니다.

## 원인

`stageRequirementFail()` 안에서 목표 미달 경고가 1회 늘어날 때마다 계급도 같이 강등시키는 코드가 남아 있었습니다.

문제 코드:

```js
if (game.rankIndex < RANKS.length - 1) game.rankIndex += 1;
```

이 때문에 5/5 로켓 방출 전에도 계급이 먼저 `방출`까지 내려갔습니다.

## 수정 내용

- 목표 미달 경고 1~4/5: 경고 카운트만 증가
- 목표 미달 경고 5/5: 그때만 `계급: 방출` 처리 후 로켓 방출 엔딩
- 즉, 4/5에서는 더 이상 `계급: 방출`이 표시되지 않습니다.
