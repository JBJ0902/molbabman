# 엔딩 갤러리 미해금 ? 카드 수정 패치 - 10종 엔딩 유지

## 원인

이전 패치는 10종 엔딩이 들어간 파일이 아니라, 5종 엔딩 구조가 남아 있던 예전 파일을 기준으로 생성되어 엔딩 개수가 5개로 되돌아갔습니다.

## 이번 수정

- 10종 엔딩 구조 유지
- 해금되지 않은 엔딩은 실제 일러스트 미리보기를 렌더링하지 않음
- 미해금 엔딩은 다크 블루 그라데이션 배경 + 큰 `?` + `미해금 엔딩` 배지로 표시
- 해금된 엔딩만 실제 썸네일 표시 및 클릭 가능

## 검증

- 패치 전 ENDING_LABELS 수: 10
- 패치 후 ENDING_LABELS 수: 10
- JS 문법 검사: OK
