# 20초 무입력 딴짓 경고 / 현재 스테이지 재시작 패치

## 변경 이유

기존에는 목표 점수/몰밥 횟수를 못 채우면 바로 '딴짓 하다 경고'가 누적되고 현재 스테이지가 재시작되었습니다.
이번 패치는 딴짓 경고 기준을 목표 미달이 아니라 플레이어의 무입력 상태로 변경합니다.

## 변경 내용

1. 밥 먹기 SPACE 또는 김치 먹기 K 입력이 20초 이상 없으면 딴짓 경고 발생
2. 경고는 우측 하단 작은 알림 박스로 표시
3. 알림 후 현재 스테이지 재시작
4. 딴짓 경고 5/5 누적 시 로켓 방출 엔딩
5. 목표 점수/몰밥 횟수 미달은 '방송 실적 부족' 소형 알림으로 분리
6. 목표 미달은 더 이상 딴짓 경고 카운트를 올리지 않음
7. 입력창/온라인 순위전 UI 단축키 차단 패치 유지

## UI 위치

- 우측 하단 상태창 바로 위쪽에 소형 경고 박스가 뜹니다.
- 모바일에서는 하단 터치 버튼 위쪽으로 이동합니다.

## GitHub 적용 방법

이번 패치는 index.html만 교체하면 됩니다.

1. index.html 전용 ZIP 압축 풀기
2. GitHub 저장소의 index.html 교체
3. Commit changes
4. Pages 재배포 완료 대기
5. 게임 페이지에서 Ctrl + F5
6. 20초 동안 SPACE/K를 누르지 않고 딴짓 경고 발생 확인
