# v9.18.20 타이머 생존 밸런스 패치

## 변경 내용

- 기존 누적 점수 목표 클리어 방식을 제거했습니다.
- 스테이지별 점수는 각 스테이지 시작 시 0점으로 초기화됩니다.
- 스테이지 클리어 조건은 점수 달성이 아니라 제한 시간 생존입니다.
- 상단 UI는 `남은 시간 / 현재 스테이지 점수 / 총점`으로 표시됩니다.
- 타이머 게이지는 남은 시간 비율로 줄어듭니다.
- 스테이지 클리어 시 현재 스테이지 점수가 총점에 누적됩니다.
- 콤보 보너스는 스테이지 클리어 시 현재 스테이지 점수에 반영됩니다.
- 다음 스테이지로 넘어갈 때 소음, 콤보, 현재 점수는 초기화됩니다.
- 최종 엔딩/기록/최고점수는 총점 기준으로 표시됩니다.

## 스테이지별 제한 시간

8. STAGE 8: 04:05

10. STAGE 10: 05:00

## 난이도 방향

- 후반으로 갈수록 수장이 더 자주 봅니다.
- WARNING 반응 시간은 줄어듭니다.
- 수장이 쳐다보는 시간은 길어집니다.
- 밥/김치 점수는 증가하지만 소음 리스크도 증가합니다.

## 적용 방법

이 ZIP 전체를 새 폴더에 압축 해제하거나, `index.html`만 기존 게임 폴더의 `index.html`에 덮어쓰기하면 됩니다.
기존 `assets/voice`, `assets/sfx`, `assets/bg`, `assets/endings` 폴더는 그대로 유지하세요.
