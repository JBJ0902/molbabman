# 말풍선 레이어 / 시작 메뉴 타이머 / 로켓 계급 수정 패치

## 수정 내용

### 1. 캐릭터 자막이 남은 시간 박스에 가려지는 문제 수정

캐릭터 팝업/말풍선 레이어를 남은 시간 패널보다 위로 올렸습니다.

- `#portraitLayer`
- `.portraitBadge`
- `#eventBubble`

위 레이어들이 `#stageTimerPanel`보다 앞에 표시되도록 z-index를 재정렬했습니다.

### 2. 시작 메뉴/엔딩 화면에서 남은 시간 박스가 앞으로 보이는 문제 수정

시작 메뉴, 옵션, 결과창, 엔딩 갤러리, 엔딩 일러스트 화면이 열려 있을 때는
`남은 시간` 패널을 숨기도록 처리했습니다.

### 3. 로켓 방출 엔딩의 최종 계급 표시 수정

로켓 방출 엔딩에서는 실제 계급 상태와 관계없이 최종 계급이 항상 `방출`로 표시됩니다.

- 결과 설명: 최종 계급: 방출
- 엔딩 일러스트 통계: 최종 계급: 방출
- 갤러리 보기: 컬렉션 상태: 방출 해금

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
