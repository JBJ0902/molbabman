# R 키 재시작 자막 표시 시간 확장 패치

## 수정 내용

R 키로 현재 스테이지를 재시작할 때 `STAGE n 재시작` 자막이 너무 빨리 START 카드에 가려지는 문제를 수정했습니다.

## 변경 후 흐름

1. R 키 입력
2. `STAGE n 재시작` 자막을 먼저 1.6초 표시
3. 약 1.75초 뒤 `STAGE n START` 카드 표시
4. 이후 현재 스테이지를 정상 재시작

## 정상 스테이지 전환 영향

정상 클리어 후 다음 스테이지로 넘어가는 흐름은 수정하지 않았습니다.
`resetCurrentStageByHotkey()` 함수 안의 R 키 재시작 흐름만 수정했습니다.

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
