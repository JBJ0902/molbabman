동꼽즈/몰밥 회의 게임 - 대화 큐 패치

적용 방법:
1. 이 압축 안의 index.html을 기존 게임 폴더의 index.html에 덮어쓰기
2. 기존 assets/voice 폴더는 그대로 유지
3. index.html 실행

수정 내용:
- WARNING/수장 시선 전환 시 진행 중인 크루/공태연 음성과 말풍선을 강제로 끊지 않음
- 수장 시선 타이머와 공태연 판정은 기존 속도 그대로 즉시 진행
- 진행 중인 음성이 끝난 뒤 수장 경고 -> 공태연 변명 대사를 큐로 재생
- WARNING 문구는 화면 경고와 효과음 중심으로 처리하여 음성 대화와 분리
- 공태연 경고/변명 대사에 쿨타임을 넣어 긴 대사 상황에서 공태연 대사만 계속 나오는 문제 완화
- pending 경고 대사가 너무 오래 밀리면 현재 상황과 어긋나지 않도록 자동 폐기

주의:
- 음성 파일 경로는 assets/voice/캐릭터명/*.mp3 기준입니다.
- 폴더명이 assets/voices가 아니라 assets/voice인지 확인하세요.
