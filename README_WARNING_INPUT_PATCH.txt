# WARNING 중 밥/김치 키 입력 허용 패치

## 수정 내용

기존에는 WARNING 메시지가 뜬 뒤에는 내부 상태가 `prewarning`인데,
밥 먹기/김치 먹기 시작 입력은 `safe` 상태에서만 허용되어 있었습니다.

이번 패치는 아래처럼 고쳤습니다.

- safe 상태: 밥/김치 입력 가능
- prewarning, 즉 WARNING 상태: 밥/김치 입력 가능
- watch, 즉 수장이 실제로 쳐다보는 상태: 누르면 즉시 적발

## 적용 방법

1. 이 ZIP 압축을 풉니다.
2. 안의 `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets/voice`, `assets/sfx` 폴더는 그대로 유지합니다.

## 확인 방법

게임 중 WARNING이 뜬 상태에서:

- SPACE: 밥 먹기 가능
- K: 김치 먹기 가능

단, WARNING 카운트가 끝나고 수장이 실제로 쳐다보는 순간까지 누르고 있으면 정상적으로 걸립니다.
