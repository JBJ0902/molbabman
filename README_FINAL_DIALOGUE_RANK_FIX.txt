# 최종 레이어/로켓 계급 강제 수정 패치 v9.18.26

## 원인

### 캐릭터 자막이 남은 시간 박스에 가려진 원인
실제 캐릭터 대사 말풍선은 `#portraitLayer`가 아니라 `#dialogueLayer > .bubble` 구조였습니다.
이전 패치는 `#portraitLayer` 위주라서 실제 말풍선에는 적용이 부족했습니다.

### 로켓 엔딩 최종 계급이 틀린 원인
파일 안에 `determineEnding()`과 `showEndingIllustrationScreen()`이 중복으로 남아 있었습니다.
브라우저는 뒤쪽에 있는 오래된 함수를 최종 적용하기 때문에, 앞쪽 함수만 고치면 다시 틀어졌습니다.

## 수정 내용

1. `#dialogueLayer`와 `.bubble`을 남은 시간 패널보다 위로 올림
2. 시작 메뉴/옵션/엔딩/갤러리 화면에서는 남은 시간 패널 숨김 유지
3. 중복된 모든 `showEndingIllustrationScreen()` 함수를 강제 교체
4. 로켓 엔딩 설명에서 최종 계급을 모두 `방출`로 고정
5. 갤러리에서는 `최종 계급` 대신 `컬렉션 상태`로 표시

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
4. 브라우저에서 Ctrl + F5로 강제 새로고침합니다.
