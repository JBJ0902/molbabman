# 강등 말풍선 → 전용 징계/계급 카드 변경 패치

## 문제

기존 `인턴으로 강등!`, `인인턴으로 강등!` 메시지는 `showEventBubble()`로 표시되어
캐릭터 말풍선처럼 보였고, 다른 자막 UI와 디자인이 이질적이었습니다.

## 수정 내용

기존:
- 강등 메시지: 캐릭터 말풍선 UI

변경 후:
- 강등 메시지: 전용 시스템 카드 UI

표시 문구:

```
⚠ 징계 처리
계급 강등
현재 계급: 인턴
```

## 위치

- 중앙 적발 배너보다 아래
- STAGE 회의 안건 패널보다 위쪽
- HUD/남은 시간 박스와 겹치지 않도록 중앙 상단 하단부에 배치

## 표시 흐름

1. `밥 먹다 걸림!` 또는 `김치 소리 감지!` 중앙 배너 표시
2. 약 0.98초 뒤 전용 `계급 강등` 카드 표시
3. 약 1.55초 후 자동 숨김

## GitHub 적용 방법

이미 GitHub Pages에 올린 상태라면:

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
