# 목표 미달 5회 로켓 방출 패치 v9.18.27

## 변경 내용

기존 목표 미달 처리:
- 목표 미달 시 목숨 -1
- 같은 스테이지 재도전

변경 후:
- 목표 미달 시 `목표 미달 경고`가 1회 증가
- 5회 누적 시 로켓 방출 엔딩
- 같은 스테이지 재도전은 1~4회까지만 진행
- 계급 강등은 기존처럼 유지

## UI 추가

좌측 남은 시간 패널 하단에 아래 항목을 추가했습니다.

목표 미달 경고 0 / 5

점으로 5칸 표시되며, 4회부터 빨간 경고 느낌이 강해집니다.

## 적용 방법

1. 압축을 풉니다.
2. index.html을 기존 게임 폴더의 index.html에 덮어쓰기합니다.
3. assets 폴더는 그대로 유지합니다.
