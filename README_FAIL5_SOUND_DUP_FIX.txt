# 목표 미달 5회 로켓 방출 중복 사운드/음성 수정 패치

## 원인

목표 미달 5회가 되는 순간에도 게임 루프가 계속 돌면서
stageRequirementFail()이 여러 번 호출될 수 있었습니다.

그 결과 아래 처리가 여러 번 쌓였습니다.

- rocket 효과음 반복 재생
- finish(false) 여러 번 예약
- 엔딩 음성 여러 번 재생
- 브라우저 오디오 객체가 중복 생성되어 랙 발생

## 수정 내용

1. 목표 미달 5회 로켓 방출은 1회만 실행되도록 objectiveRocketLocked 추가
2. finish()는 1회만 실행되도록 finishLocked 추가
3. launchRocketEnding()도 중복 실행 방지
4. 목표 미달 5회 시 기존 대화/음성 즉시 정리
5. rocket 효과음은 목표 미달 5회에서 1번만 재생
6. 엔딩 메시지 음성은 finish() 1회에서만 재생
7. 엔딩 음성 시작에 약간의 딜레이를 넣어 rocket 효과음과 겹침 감소

## 적용 방법

1. 압축을 풉니다.
2. index.html을 기존 게임 폴더의 index.html에 덮어쓰기합니다.
3. assets 폴더는 그대로 유지합니다.
