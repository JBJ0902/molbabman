# 딴짓 경고 카운트다운 가시성 수정 패치

## 문제

영상에서 딴짓 경고 카운트다운이 보이지 않고,
20초 후에 바로 딴짓 경고가 발동되는 것처럼 보였습니다.

## 원인

이전 패치는 카운트다운 표시가 마지막 10초부터만 뜨고,
알림 박스를 매 프레임 다시 생성하는 방식이라 실제 화면에서 잘 안 보일 수 있었습니다.

## 수정 내용

1. 무입력 3초 경과 후부터 카운트다운 카드 표시
2. 20초까지 진행 바가 계속 차오름
3. 카운트다운 카드는 매 프레임 재생성하지 않고 내용만 갱신
4. 20초 도달 시 딴짓 경고 1포인트만 누적
5. 5포인트 누적 전에는 스테이지 재시작하지 않음
6. 카운트다운 카드 z-index와 위치를 보정해서 상태창/경고창 뒤에 숨지 않게 처리

## GitHub 적용 방법

이번 패치는 index.html만 교체하면 됩니다.

1. index.html 전용 ZIP 압축 풀기
2. GitHub 저장소의 index.html 교체
3. Commit changes
4. Pages 재배포 완료 대기
5. 게임 페이지에서 Ctrl + F5
6. 게임 시작 후 3초 동안 SPACE/K를 누르지 않아 카운트다운 카드가 뜨는지 확인
