# WARNING 초 단위 힌트 제거 / 경고 박스 정리 패치

## 수정 내용

기존 WARNING 문구:

```
WARNING 곧 수장님이 쳐다봅니다! 약 x.x초 안에 손을 떼세요
```

변경 후:

```
곧 수장님이 쳐다봅니다.
```

## 변경 이유

`약 x.x초 안에 손을 떼세요` 문구가 정확한 회피 타이밍을 알려줘서
게임 난이도를 낮추는 문제가 있었습니다.

## 추가 조정

1. 경고 박스에서 초 단위 안내 제거
2. `WARNING` 영문 문구도 제거하고 한국어 경고 문구만 표시
3. 상태창의 “지금 손을 떼면 안전” 같은 직접 힌트성 문구 제거
4. 경고 박스 크기 축소
5. 경고 박스 위치를 상단 중앙에 보기 좋게 재배치
6. 모바일/좁은 화면용 위치도 별도 조정

## GitHub 적용 방법

이미 GitHub Pages에 올린 상태라면:

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
