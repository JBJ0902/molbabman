# 소음 100% 적발 카드 / demote 음성 분기 패치

## 문제

소음 경계도 100%가 되었을 때 `김치 씹는 소리가 너무 큽니다!` 문구가
하얀색 캐릭터 말풍선으로 표시되어 디자인이 어색했고,
이후 강등 카드/배너와 겹쳐 보였습니다.

## 수정 내용

### 1. 소음 100% 전용 카드 추가

기존:
- 하얀 말풍선: `김치 씹는 소리가 너무 큽니다!`

변경:
- 전용 시스템 카드:
  - `⚠ 소음 경계도 100%`
  - `김치 소리 감지` 또는 `밥 먹는 소리 감지`
  - 상황 설명 1줄

### 2. 겹침 방지

- 소음 적발 카드는 약 0.9초 표시
- 그 뒤 계급 강등 카드가 표시됨
- 기존 하얀 말풍선은 제거

### 3. demote 음성 분기

소음 경계도 100%로 인턴 강등:
- 김치 소리 적발 → `assets/voice/demote_1.mp3`
- 밥 먹는 소리 적발 → `assets/voice/demote_2.mp3`

수장님 시선에 직접 밥/김치 먹다 걸림:
- 직접 적발 → `assets/voice/demote_3.mp3`

### 4. 기존 런타임 오류 가능성 제거

이전 강등 처리에 남아 있던 존재하지 않는 `playVoice()` 호출을 제거하고,
실제 존재하는 `playVoiceClip()`으로 통일했습니다.

## GitHub 적용 방법

이미 GitHub Pages에 올린 상태라면:

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
