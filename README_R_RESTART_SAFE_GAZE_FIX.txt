# R 키 재시작 직후 공태연 즉시 시선 방지 패치

## 문제 원인

R 키로 현재 스테이지를 재시작할 때 이전 phase가 WARNING 또는 WATCH 상태로 남아 있으면,
재시작 직후 공태연을 바로 쳐다보는 것처럼 보일 수 있었습니다.

또한 재시작 카드가 뜨는 동안에도 일부 타이머가 진행되어,
START 카드가 끝난 직후 빠르게 WARNING으로 넘어가는 경우가 있었습니다.

## 수정 내용

1. R 재시작 직후 phase를 `stageRestart`로 고정
2. 재시작 카드 표시 중에는 스테이지 타이머 감소 중단
3. 재시작 직후 시선을 중앙 안전 시선으로 고정
4. 재시작 카드가 끝난 뒤 `setSafePhase()` 실행
5. 첫 WARNING까지 최소 4.5초의 안전 시간 보장
6. stageRestart 중에는 회의 대화 큐도 실행하지 않음

## 적용 후 흐름

R 키 입력
→ STAGE n 재시작 카드 표시
→ 카드가 끝날 때까지 안전 상태 고정
→ 카드 종료 후 최소 4.5초 동안 공태연을 보지 않음
→ 이후 일반 시선 패턴 진행

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
