# 몰밥 회의실 서버이벌 v9.18.22 엔딩 갤러리 패치

## 추가 기능

1. 엔딩 갤러리 추가
   - 시작 화면, 결과 화면, 엔딩 일러스트 화면에서 열 수 있습니다.
   - 해금된 엔딩은 클릭하면 일러스트로 다시 볼 수 있습니다.
   - 미해금 엔딩은 조건과 힌트를 표시합니다.

2. 엔딩창 하단 빈 공간 개선
   - 컬렉션 진행률
   - 현재 엔딩 획득 조건
   - 다음 목표 엔딩 힌트
   를 표시하는 패널을 추가했습니다.

3. 기존 `해금 여부: 완료` 문구 제거
   - 단순 문구 대신 갤러리 진행률 시스템으로 대체했습니다.

## 적용 방법

index.html을 기존 게임 폴더의 index.html에 덮어쓰기하면 됩니다.
assets 폴더는 그대로 유지하세요.

## 참고

엔딩 해금 기록은 기존 localStorage 기록을 그대로 사용합니다.
기록 초기화 버튼을 누르면 엔딩 갤러리 해금 기록도 함께 초기화됩니다.
