# 밥/김치 적발 문구·효과음 분리 패치

## 변경 내용

밥 먹다 걸렸을 때와 김치 먹다 걸렸을 때의 큰 경고 문구와 효과음을 분리했습니다.

### 밥 먹다 걸렸을 때

큰 경고:
밥 먹다 걸림!

상태창:
밥 먹는 장면이 들켰습니다. 현재 계급: ...

효과음:
rice.mp3 + caught.mp3

### 김치 먹다 걸렸을 때

큰 경고:
김치 소리 감지!

상태창:
김치 씹는 소리가 들켰습니다. 현재 계급: ...

효과음:
kimchi.mp3 + caught.mp3

## 소음 경계도 100% 적발 처리

소음 경계도 100%로 걸리는 경우에도 마지막으로 먹고 있던 타입을 기준으로 같은 문구와 효과음을 출력합니다.

- 밥 먹다가 소음 100% → 밥 먹다 걸림!
- 김치 먹다가 소음 100% → 김치 소리 감지!

## 적용 방법

1. 압축을 풉니다.
2. index.html을 기존 게임 폴더의 index.html에 덮어쓰기합니다.
3. assets 폴더는 그대로 유지합니다.
