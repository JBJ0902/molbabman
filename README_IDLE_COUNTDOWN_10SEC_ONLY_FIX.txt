# 딴짓 경고 카운트다운 10초 시작 수정 패치

## 변경 내용

요청대로 아래 한 가지만 변경했습니다.

- 기존: 무입력 3초 경과 후부터 카운트다운 카드 표시
- 변경: 무입력 10초 경과 후부터 카운트다운 카드 표시

나머지 기능은 변경하지 않았습니다.

## 유지되는 기능

- 20초 무입력 시 딴짓 경고 1포인트 누적
- 5포인트 누적 시 현재 스테이지 재시작
- 옵션 메뉴 일시정지
- 온라인 순위전/Google 로그인 기능
- 카운트다운 카드 UI / 진행바 / z-index 보정

## GitHub 적용 방법

이번 패치는 index.html만 교체하면 됩니다.

1. index.html 전용 ZIP 압축 풀기
2. GitHub 저장소의 index.html 교체
3. Commit changes
4. Pages 재배포 완료 대기
5. 게임 페이지에서 Ctrl + F5
6. 게임 시작 후 10초 동안 SPACE/K를 누르지 않아 카운트다운 카드가 뜨는지 확인
