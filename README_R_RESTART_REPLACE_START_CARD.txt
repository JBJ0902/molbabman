# R 키 재시작 START 카드 대체 표시 패치

## 수정 내용

R 키로 현재 스테이지를 재시작할 때 별도 `STAGE n 재시작` 자막을 띄우지 않고,
기존 중앙 `STAGE n START` 카드 자체를 `STAGE n 재시작` 카드로 대체하도록 변경했습니다.

## 변경 후 흐름

R 키 입력
→ 중앙 카드가 `STAGE n 재시작`으로 표시
→ 약 1.55초 뒤 현재 스테이지를 처음부터 시작

## 정상 스테이지 전환 영향

정상적으로 스테이지를 클리어해 다음 스테이지로 넘어갈 때는 기존처럼 `STAGE n START` 카드가 표시됩니다.
R 키 재시작 때만 `RESTART MEETING / STAGE n 재시작` 카드가 표시됩니다.

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.
