# 로켓 방출 엔딩 음성 끊김 수정 패치

## 문제

로켓 방출 엔딩으로 넘어갈 때 음성이 다음처럼 부자연스럽게 끊겼습니다.

1. 로켓 발사 연출 음성:
   `발사 엔딩입니다. 몰밥할 때...`

2. finish(false) 진입 시 stopSpeaking()으로 앞 음성이 끊김

3. 곧바로 최종 엔딩 음성:
   `로켓 방출 엔딩입니다. 다음에는 몰밥할 때...`

즉, 로켓 발사 연출 음성과 엔딩 결과 음성이 서로 겹치고 끊기는 구조였습니다.

## 수정 내용

1. `launchRocketEnding()`에서는 로켓 효과음만 재생
2. 로켓 발사 연출 안내 음성은 제거
3. 최종 엔딩 화면에서 로켓 방출 엔딩 음성만 1회 재생
4. 로켓 엔딩 음성은 결과창 표시 후 약 0.9초 뒤 재생
5. 엔딩 음성 타이머를 `game._endingVoiceTimer`로 관리해서 중복 재생 방지
6. resetGame()에서 엔딩 음성 타이머 정리

## 변경 후 흐름

로켓 연출:
- 로켓 효과음
- ROCKET LAUNCH 배너
- 음성 없음

엔딩 화면:
- GAME OVER / 로켓 방출 엔딩 표시
- 약 0.9초 뒤 로켓 방출 엔딩 음성 1회 재생
