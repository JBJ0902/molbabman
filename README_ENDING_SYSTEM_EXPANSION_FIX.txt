# 엔딩 시스템 10종 확장 / 조건 강화 패치

## 변경 요약

기존 5종 엔딩을 10종 엔딩 구조로 확장했습니다.

## 최종 엔딩 목록

1. 레전드 1검 정직원 엔딩
2. 정직원 엔딩
3. 김치왕 엔딩
4. 밥심 정직원 엔딩
5. 무소음 몰밥 엔딩
6. 몰밥 콤보 장인 엔딩
7. 줄타기 생존 엔딩
8. 막판 역전 정직원 엔딩
9. 인턴 생존 엔딩
10. 로켓 방출 엔딩

## 주요 조건 변경

### 레전드 1검 정직원 엔딩

기존:
- 목숨 5개
- 정직원 유지

변경:
- 10스테이지 클리어
- 목숨 5개
- 정직원 유지
- 적발 0회
- 몰밥 미션 실패 0회
- R 재시작 0회
- 최대 콤보 35 이상
- 최종 점수 95,000점 이상

### 정직원 엔딩

기존 `생존 성공 엔딩`을 `정직원 엔딩`으로 변경했습니다.

조건:
- 끝까지 클리어
- 레전드 1검 조건은 못 채움
- 인턴까지 강등되지 않음
- 다른 특수 엔딩 조건에 해당하지 않음

### 김치왕 엔딩

기존:
- 최대 콤보 20 이상

변경:
- 김치 키만 사용해서 10스테이지 클리어
- 밥 키 사용 기록이 있으면 발동하지 않음

### 밥심 정직원 엔딩

신규 추가:
- 밥 키만 사용해서 10스테이지 클리어
- 김치 키 사용 기록이 있으면 발동하지 않음

## 신규 기록값

엔딩 판정을 위해 아래 기록을 추가했습니다.

- 밥 몰밥 횟수
- 김치 몰밥 횟수
- 밥 키 사용 여부
- 김치 키 사용 여부
- 적발 횟수
- 소음 적발 횟수
- 수장 시선 적발 횟수
- R 재시작 횟수
- 최고 소음 경계도

## 주의

새 엔딩은 기존 assets를 그대로 재활용합니다.
따라서 GitHub에는 `index.html`만 교체하면 됩니다.

## GitHub 적용 방법

1. 이 패치의 `index.html`만 기존 GitHub 저장소의 `index.html`에 덮어쓰기
2. Commit changes
3. Pages 재배포 완료 대기
4. 게임 페이지에서 Ctrl + F5

assets 폴더는 다시 올릴 필요 없습니다.
