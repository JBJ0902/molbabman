# HUD 간소화 / 소음 경계도 확장 패치

## 적용 내용

1. 상단 HUD에서 목숨 박스 숨김
   - 내부 목숨 시스템은 그대로 유지됩니다.
   - 게임오버/강등/엔딩 판정에는 영향 없습니다.

2. 점수/총점 칸 그래프 바 제거
   - 숫자만 표시합니다.
   - 점수/총점 표시는 유지합니다.

3. 소음 경계도 칸 확장
   - 점수 바를 제거한 공간을 활용해서 소음 게이지를 더 길게 표시합니다.

4. HUD 재배치
   - STAGE / 계급 / 콤보 / 최고점수 / 소음 경계도 / 점수·총점 / 옵션 순서로 정리했습니다.

## 콤보 배수 시스템

현재 게임의 콤보는 점수 배율 시스템입니다.

- 밥 또는 김치를 계속 먹고 있으면 약 0.65초마다 콤보 +1
- 먹지 않고 멈추면 안전 구간에서 1초마다 콤보 -1
- 콤보 3마다 배수 +0.2
- 최대 배수는 x3.0

예시:

- 콤보 0~2: x1.0
- 콤보 3~5: x1.2
- 콤보 6~8: x1.4
- 콤보 9~11: x1.6
- 콤보 30 이상: x3.0

점수 계산은 대략 아래 구조입니다.

점수 증가량 = 밥/김치 기본 점수 × 현재 배수 × 시간

즉 오래 몰래 먹을수록 점수가 빨리 오르지만,
그만큼 소음과 적발 위험이 커지는 리스크/보상 장치입니다.
