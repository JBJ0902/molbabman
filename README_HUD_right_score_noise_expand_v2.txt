# HUD 우측 정렬 / 소음 경계도 확장 v2 패치

## 수정 내용

1. 최고점수 박스를 우측으로 이동
2. 점수/총점 박스를 우측으로 이동
3. 점수/총점 박스 너비 축소
4. 점수/총점 그래프 바는 계속 제거
5. 소음 경계도 박스와 게이지 바의 가로폭 확장
6. 목숨 박스는 계속 숨김

## 적용 방법

1. 압축을 풉니다.
2. `index.html`을 기존 게임 폴더의 `index.html`에 덮어쓰기합니다.
3. `assets` 폴더는 그대로 유지합니다.

## 위치 조정 팁

소음 경계도 길이를 더 늘리고 싶으면 CSS에서 아래 값을 조정하세요.

```css
#suspicionPanel {
  grid-column: 9 / span 7;
}
```

`span 7`을 `span 8`로 늘리면 소음 칸이 더 길어집니다.
대신 오른쪽 최고점수/점수 칸과 겹칠 수 있습니다.

점수/총점 박스를 더 줄이고 싶으면:

```css
#scorePanel {
  grid-column: 20 / span 3;
}
```

처럼 `span 4`를 `span 3`으로 줄이면 됩니다.
